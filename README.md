# CTS Prep Hub (merged into CTS Prep)

This repository was merged into **[CTS-Prep](https://github.com/Isaacred718/CTS-Prep)**.

CTS Prep contained everything in this repository plus newer work (more
questions, flashcards and guides, the Ravenna and AES67 section, the
installable app, and the Android and Meta Quest builds), so it is now the
single home of the app. Nothing here was unique: every question, card, guide
and drill from this repository is present in CTS Prep.

What remains here:

- `index.html` sends visitors of the old address to CTS Prep. Both sites share
  the same storage on `isaacred718.github.io`, so progress saved on a device
  carries over without any export.
- `sw.js` retires the old offline worker.

The full history of this repository is unchanged. Once the redirect has been
live for a while, the repository can be archived in its GitHub settings.
